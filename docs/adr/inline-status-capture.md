# Boards create children inline in the selected status

Each status group has an add row. Entering a title and pressing Enter creates a child in that group's status. A plain checklist has one add row that creates the child in Backlog. Expanded cards have no add row.

Inline capture removes the steps of opening a creation dialog and keeps the chosen status attached to the new item. The trade-off is that quick capture can add work faster than a person can organize it.

## Considered options

A creation dialog can collect more fields, but makes capture slower. Creation through the CLI alone leaves the board as a read-only surface.

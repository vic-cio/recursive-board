# Match card titles to note text and keep checklist links quiet

Card titles use the theme's note text font and size, matching checklist row titles. A collapsed card face omits the work item's id; the expanded card and its menu provide it. Checklist links use text color until hover, when they use the accent color and underline, while keeping Obsidian's page preview.

This gives the same work item a consistent reading scale in a card or checklist. Larger titles can wrap and make cards taller, and ids take an extra action to copy from the menu.

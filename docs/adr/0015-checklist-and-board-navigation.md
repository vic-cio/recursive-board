# Work item children open as a checklist unless the item is promoted

Opening a work item shows its children as an ordered checklist. A promoted item shows its children in a board organized by four statuses. Children inside an expanded card remain a checklist. This keeps navigation recursive without repeating a full board at every depth.

## Considered options

Showing a board whenever an item has children makes the interface change when deeper work changes. A checklist by default keeps the work item readable, while promotion marks the items that need their own board.

# Status colours are user-configurable

The plugin lets a user override the theme-derived colours for options, doing, done, blocked, and agent badges. Overrides live in the plugin's `data.json`, which Obsidian can sync with the vault. Reset removes an override and returns to the current theme colour. The selected colour supplies the tint; saturated text continues to use Obsidian's status theme colour so the existing light and dark contrast treatment stays intact.
